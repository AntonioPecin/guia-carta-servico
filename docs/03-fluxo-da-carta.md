# Como a carta anda no CMS

```
Coordenador escreve  →  Gerente envia  →  Aprovador Central (CGE) aprova  →  Portal
                                       ↘  devolve com apontamentos  →  Pendente de correção  →  volta ao Gerente
```

| Situação | Quem age |
|---|---|
| Salvo como rascunho | Coordenador, Gerente ou Administrador editam |
| Enviado para aprovação | Gerente ou Administrador enviaram; o Gerente pode cancelar o envio |
| Publicado | Aprovador Central aprovou; publica na hora (não há agendamento) |
| Pendente de correção | Aprovador Central devolveu, com o motivo de cada campo |

Regras que aparecem no guia:
- Só existe **um rascunho** por carta.
- Nova versão publicada substitui a anterior, que vai para o histórico.
- Aprovar publica na hora.
